OpenAliceのインストールとクイックスタート：5分でAIトレーディングエージェントを起動する

2026年4月15日·8 min read

インストールドキュメントが美しいツールはたくさんあります——しかし実際に従ってみると、前提条件が3つ足りなかったり、バージョンの不一致があったり、PORTが競合していたりして、GitHub issuesで解決策を探す羽目になります。

このガイドはそういった落とし穴をあらかじめ指摘するよう努めており、実際に5分でOpenAliceの最初の会話にたどり着けるようにします。

前提条件

OpenAliceの環境要件は多くありませんが、この3つはすべて正確に揃っている必要があります：

ツール バージョン 備考
Node.js 22以上 古いバージョンは動作しません——nvmで管理することを推奨
pnpm 10以上 npm install -g pnpmまたはCorepackでインストール
Claude Code CLI 最新 デフォルトのAIプロバイダー；Pro/Maxサブスクリプションを使用

Claude Codeについて：OpenAliceはClaude CodeのAgent SDKを通じてOAuthをサポートするため、これがデフォルトのAIプロバイダーです——つまり、Anthropic APIキーは別途不要で、Claude Pro/Maxサブスクリプションで十分です。

自分のAPIキーを使いたい場合（Vercel AI SDKモード、OpenAI・Google・Anthropicに対応）、Claude Codeはオプションになります。

バージョン確認：

3つすべて確認できれば、準備完了です。

インストール手順

ステップ1：クローンとインストール

pnpm installはすべての依存関係を取得し、pnpm buildはバックエンドとUIの両方をビルドします。初回は少し時間がかかることがあります——これは正常です。

ステップ2：開発モードを起動

バックエンド（ポート3002）を起動し、ビルド済みのUIを提供します。

ブラウザを開いてhttp://localhost:3002にアクセス——OpenAliceのWeb UIチャットインターフェースが表示されるはずです。

ステップ3：最初の会話

チャットボックスに直接入力：

What's the current price of AAPL?

最初のレスポンスは接続の初期化中に少し遅くなることがあります。正確な株価データが返ってきたら、おめでとうございます——OpenAliceが動いています。

2つの開発モード

OpenAliceは異なるシナリオ向けに2つのコマンドを提供しています：

コマンド ポート ユースケース
pnpm dev 3002 バックエンドウォッチモード（tsx）、ビルド済みUIを提供
pnpm dev:ui 5173 ホットリロード付きフロントエンドVite開発サーバー、APIを3002にプロキシ

通常の使用：pnpm devで十分です。
UIを修正する場合：ターミナルを2つ開き——一方でpnpm dev、もう一方でpnpm dev:uiを実行し、http://localhost:5173でアクセス。UIの変更がリアルタイムで反映されます。

よくあるインストール問題

Q: pnpm buildが失敗する。Nodeバージョンは問題ないのに
pnpmのキャッシュ問題を確認：pnpm store prune && pnpm install --force

Q: サーバーが起動したが会話に反応がない
Claude Code CLIがログインしているか確認：claude auth status。ログインしていないと表示されたら、claude auth loginを実行してOAuthフローを完了させてください。

Q: ポート3002がすでに使用されている
lsof -i :3002でそのポートを使っているプロセスを見つけ、終了させてからpnpm devを再実行してください。

Q: 自分のOpenAI APIキーに切り替えたい
OpenAliceは複数のAIプロバイダープロファイルをサポートしており、設定UIで切り替えられます。設定はWeb UIのConfigページにあります——Vercel AI SDKを選択してAPIキーを入力してください。

Web UIのクイックツアー

起動したら、いくつかのエリアが見えます：

  • チャットインターフェース — Aliceと会話する場所；サブチャンネルをサポートするので、異なる市場やタスクごとに異なるチャンネルを開けます
  • ポートフォリオダッシュボード — 接続したUTA口座のポジションを表示、資産曲線の可視化を含む
  • Config管理 — AIプロバイダー・証券口座・ガードパイプラインルールを設定する場所

ポートフォリオダッシュボードは最初は空かもしれません——まだ証券口座を接続していないからです。それで問題ありません。まずリサーチ・分析機能に慣れ、準備ができたら実際の口座を設定しましょう。

最初に試すべき練習

起動したら、OpenAliceが何をできるかを感じるためにこれらのプロンプトを試してみてください：

# 価格クエリ
TSLA の52週高値と52週安値を教えて

# テクニカル分析
過去30日間のBTC/USDのRSIとMACDを見せて

# ニュース検索
FRBの金利決定に関する最新ニュースは？

# ファンダメンタルズ
NVDAの最新決算報告の概要を教えて

すべて試す必要はありません——気になる1〜2つの市場を選んでいくつかクエリを実行してください。目的はOpenAliceのレスポンス速度、データの深さ、質問の理解度を感じ取ることです。

次の設定ステップ

動いたら、さらに深掘りしたい場合の次のステップは通常：

  1. ガードパイプラインの設定 — ConfigでAIに動かしてよいトレーディング境界を定義する
  2. 証券口座の接続 — Unified Trading Accountを作成し、実際の口座を統合する
  3. Heartbeatの設定 — OpenAliceが気になる市場状況を能動的にモニタリングし始めるよう設定する

これらを一度にすべてやる必要はありません。まずリサーチワークフローをスムーズに動かし、それから徐々に執行権限を開放していく——それがより着実なアプローチです。

一言で

OpenAliceのインストールは難しくありません——難しいのは、動いてから本当に役に立てる方法を知ることです。環境を立ち上げることはスタート地点に過ぎません。本当の仕事はその後から始まります。
