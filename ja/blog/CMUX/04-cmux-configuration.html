CMUX設定完全ガイド：フォント・カラー・スクロールバック・分割ペイン

2026年3月29日·6 min read

設定は通常、どこかで詰まったときに調べるものだ。しかしCMUXはGhosttyから設定を継承しているため、Ghosttyを使ったことがないと、どのファイルを探せばいいかすらわからないかもしれない。この記事では全てを一か所でカバーする。

設定ファイルの場所

CMUXは以下の順番で2つの場所から設定ファイルを探す：

~/.config/ghostty/config
~/Library/Application Support/com.mitchellh.ghostty/config

最初のパスが推奨 — より直感的でバージョン管理しやすい。

設定ファイルがまだ存在しない場合は作成する：

好みのエディタでこのファイルを開き、全ての設定をここに書く。

外観設定

フォント

font-family = JetBrains Mono
font-size = 14

font-familyにシステムにインストールされているフォントの名前を設定する。見つからない場合、CMUXはデフォルトにフォールバックする。コード用にはJetBrains MonoやFira Codeが人気 — 好みで選べばいい。

カラーとテーマ

プリセットテーマを使うか、各カラーを手動で指定するかを選べる：

# ビルトインテーマを使用
theme = Dracula

# または各値をカスタマイズ
background = #1e1e2e
foreground = #cdd6f4
cursor-color = #f5e0dc
cursor-text = #1e1e2e
selection-background = #585b70
selection-foreground = #cdd6f4

どちらか一方を選ぶ — 両方同時に設定しないこと。Catppuccin、One Dark、Nordなど好みがあれば、テーマ名を入れるだけで完了。

分割ペインの外観

複数ペインがある場合、フォーカスしていないペインを少し暗くすると、アクティブなworkspaceが視覚的に際立つ：

# フォーカスしていないペインの不透明度（0.0 = 完全透明、1.0 = 完全不透明）
unfocused-split-opacity = 0.7

# フォーカスしていないペインの塗りつぶし色
unfocused-split-fill = #1e1e2e

# ペイン区切り線の色
split-divider-color = #45475a

unfocused-split-opacity = 0.85がよく使われる中間値 — フォーカスを区別できるほど暗く、隣のペインの出力をまだ読めるほど明るい。

動作設定

スクロールバックバッファサイズ

scrollback-limit = 10000

AIエージェントは大量の出力を生成できる。長いログをスクロールして戻りたい場合、この値は十分に大きくする必要がある。デフォルトでは不十分かもしれない — 50000から100000がより安全な範囲。

デフォルト作業ディレクトリ

working-directory = ~/Projects

新しく開いたworkspaceとペインはこのディレクトリから開始する。プロジェクトルートに設定するのが便利なデフォルト。

アプリ内設定

一部のオプションは設定ファイルではなく、CMUXアプリケーション内で設定する：

メニューバー → cmux > 環境設定（⌘,）、以下が見つかる：

テーマモード：System（macOSに従う）、Light、Dark — どれか選ぶ。

自動化モード（重要）：ソケットAPIのアクセスレベルを制御する：

  • Disabled：ソケット非公開、最もセキュア — 共有マシンに適切
  • cmux processes only：CMUXターミナル内で起動したプロセスのみ接続可能 — これが最も一般的な選択
  • allowAll：任意のローカルプロセスが接続可能 — 自動化が多い個人マシンに適切

個人の開発マシンでは「cmux processes only」が標準的な選択。CI環境やスクリプトが多い設定の場合のみallowAllを検討する。

ブラウザリンクの動作：環境設定 > Browserで2つのリストを設定できる：

  • ビルトインブラウザで開くホスト：ターミナル出力のリンクをクリックしたとき、どのホストをCMUXのビルトインブラウザで開くか
  • HTTP許可ホスト：どのHTTP（非HTTPS）ホストをビルトインブラウザで開けるか — localhostと127.0.0.1はデフォルトで含まれている

完全な設定例

そのままコピーして必要に応じて調整する：

# ~/.config/ghostty/config

# フォント
font-family = SF Mono
font-size = 13

# テーマ
theme = One Dark

# スクロールバック
scrollback-limit = 50000

# 分割ペイン
unfocused-split-opacity = 0.85
split-divider-color = #3e4451

# 作業ディレクトリ
working-directory = ~/code

ファイルを保存してCMUXを再起動すると変更が反映される。
