Gstack インストールとクイックスタート：10 分で 9 つの Skill をセットアップ

2026年4月19日·7 min read

多くのツールの「インストールガイド」はこんな感じです：10 のステップがあり、7 番目でエラーが出て、エラーメッセージを Google で検索し始め、2 時間後もまだ動いていない。

Gstack はそうではありません——インストールは本当に 2 つのコマンドだけで、プロセス全体を Claude 自身が実行します。

唯一の前提条件：Claude Code、Git、Bun v1.0+ が必要です。この 3 つがあれば、読み進めてください。

個人インストール（最も一般的な方法）

Claude Code を開き、このコマンドを貼り付けて Claude に実行させます：

Claude が行うこと：

  • repo 全体を ~/.claude/skills/gstack/ にクローン
  • 各 skill のシンボリックリンクを作成
  • /browse に必要な Chromium バイナリをコンパイル（約 58MB、macOS / Linux どちらも対応）
  • node_modules をインストール

プロセス全体で約 2-5 分かかり、主にバイナリのコンパイル待ちです。PATH の設定不要、sudo 不要——すべて .claude/ 内に配置されます。

インストール確認

インストールが完了したら、Claude Code で任意の slash command を試します：

/plan-ceo-review

Claude が「評価したい機能やアイデアは何ですか？」といった質問をし始めたら、インストール成功です。

反応がない場合は、シンボリックリンクが正しく作成されているか確認します：

gstack/ ディレクトリと各 skill のシンボリックリンク（plan-ceo-review、review、ship など）が表示されるはずです。

よくある質問

Q：./setup が途中で止まった？
バイナリのコンパイル中によく起こります。Bun が 1.0 以上であることを確認し、古いバージョンの場合は先にアップグレードしてください：bun upgrade。

Q：/browse をインストールしたが Chromium が起動失敗？
macOS または Linux（x64 / arm64）であることを確認してください。Windows では現在 /browse と /qa のブラウザ機能がサポートされていません。他の skill は正常に使用できます。

Q：最新バージョンに更新したい？
Claude Code で /gstack-upgrade を実行すると、インストール方法（グローバルまたは repo 内）を自動検出して更新し、変更内容を教えてくれます。

Q：トークン消費が想定より多い？
Gstack の各 skill には一定のコンテキスト初期化コストがあり、複雑なレビュータスクでは 10K+ トークン消費することがあります。選択的に使うことをお勧めします——すべての skill を開く必要はありません。新機能開発には /plan-ceo-review + /plan-eng-review、リリース前には /review + /qa で十分です。

インストール後、最初にやるべき 3 つのこと

1. /plan-ceo-review を実行して感触を掴む

最近検討している機能や意思決定を一つ選んで、正式でなくていいです。「アプリに通知システムを追加したい」と言って、Gstack の CEO モードがどう応答するかを見てみましょう。

いつもの Claude との会話と明確な違いを感じるはずです——「わかりました、こう設計しましょう」とはならず、まずあなたが考えていなかったかもしれない質問をいくつかしてきます。

2. 実際のコードで /review を試す

「たぶん問題ない」と思っているコードを選んで /review に投げてみてください。初めて使う人の多くが驚きます——見つかる問題はタイポではなく、「普段は気にしないが高トラフィック下でクラッシュする」タイプのものです。

3. /setup-browser-cookies を設定する（/qa を使う場合）

アプリにログイン機能がある場合、/qa を実行する前にこのコマンドでセッション cookies をインポートする必要があります——そうしないと、AI がテストするのは全部未ログイン状態のページになり、重要な機能がテストできません。

このステップはすぐ終わります。インタラクティブな picker が開いて、どのドメインの cookies をインポートするかを選べます。プロセス全体で cookie の値は画面に表示されません。

インストール完了、基本コンセプトも把握できました——次は Gstack の最も価値ある部分へ：Plan Review。
