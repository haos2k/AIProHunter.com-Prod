Base de Conocimientos + RAG de DeepTutor: Enseñando a la IA tus Datos Privados

20 4月 2026·6 min read

El uso de IA que hace la mayoría de personas tiene una limitación significativa: solo conoce lo que está en sus datos de entrenamiento.

Los documentos internos de tu empresa, tus notas del curso, los artículos académicos que has recopilado—ChatGPT no sabe nada de eso. Cada vez que necesitas trabajar con este material, o lo encuentras tú mismo, pegas grandes bloques de texto para que la IA lea, o esperas que pueda adivinar el contenido correcto.

La Base de Conocimientos de DeepTutor resuelve este problema: enseñar a la IA tus propios datos, luego llamarlos directamente durante conversaciones, investigación y quizzes.

Cómo Funciona la Base de Conocimientos

El backend de la base de conocimientos de DeepTutor usa LightRAG—un framework RAG (Retrieval-Augmented Generation) construido sobre grafos de conocimiento.

¿Qué lo hace diferente del RAG tradicional?

El RAG tradicional es búsqueda vectorial pura: divide los documentos en segmentos, los convierte a vectores, encuentra los segmentos más similares en el momento de la consulta. El problema es que maneja similitud textual superficial, no relaciones entre conceptos.

LightRAG agrega una capa de grafo de conocimiento sobre la búsqueda vectorial—construye una red semántica a partir de entidades (nombres, conceptos, terminología) y las relaciones entre ellas encontradas en tus documentos. En el momento de la consulta, no solo encuentra pasajes similares; sigue enlaces conceptuales para razonar entre ellos.

El efecto práctico: cuando preguntas "¿Cuál es la diferencia entre LightRAG y el RAG tradicional?", no solo devuelve segmentos que contienen esos dos términos—trae junto con ello el contexto de todos los conceptos relacionados en tu base de conocimientos.

Construyendo tu Primera Base de Conocimientos

Paso 1: Acceder a la gestión de la base de conocimientos

Haz clic en "Base de Conocimientos" en el panel de navegación izquierdo de DeepTutor, luego crea una nueva base de conocimientos.

Organiza por tema—no pongas todo en una sola base:

Base de Conocimientos A: Fundamentos de Machine Learning (libros de texto, notas del curso)
Base de Conocimientos B: Diseño de Sistemas (resúmenes de libros, notas de soluciones LeetCode)
Base de Conocimientos C: Documentos de Trabajo (especificaciones internas, RFCs técnicos)

Bases separadas significan consultas más precisas, recuperación más enfocada y sin interferencia entre temas.

Paso 2: Subir documentos

Formatos actualmente soportados:

  • PDF (el más común; las versiones escaneadas funcionan, pero los PDFs basados en texto tienen mejor rendimiento)
  • Markdown (archivos .md—mejores resultados para la construcción del grafo de conocimiento)
  • Texto plano (.txt)

Solo arrastra y suelta o haz clic para subir. DeepTutor maneja la indexación en segundo plano—no necesitas esperar. La indexación normalmente se completa en unos pocos minutos a decenas de minutos dependiendo del tamaño y cantidad de archivos.

Paso 3: Confirmar el estado de indexación

En la página de gestión de la base de conocimientos, cada documento muestra su estado de indexación:

  • Procesando: Construyendo el índice
  • Listo: Índice completo, disponible para uso
  • Error: La indexación falló (generalmente un problema de formato PDF—intenta convertir y volver a subir)

Usando la Base de Conocimientos en Conversaciones

Una vez que la indexación está completa, puedes especificar qué base de conocimientos usar en cualquier modo:

"(Usando base de conocimientos: Fundamentos de Machine Learning)
Basándote en mis notas, explica la diferencia entre Gradient Descent y Adam Optimizer—
enfócate específicamente en las estrategias de ajuste de tasa de aprendizaje que mencioné."

Sin especificar una base de conocimientos, DeepTutor recurre a su conocimiento de entrenamiento base. Cuando especificas una, prioriza tus datos privados y complementa con su propio conocimiento según sea necesario.

Cinco Estrategias para Mejor Calidad de Recuperación

Esta es la razón por la que muchas personas encuentran "a veces no coincide con lo que está en mis documentos" después de configurar una base de conocimientos. La calidad de recuperación RAG depende en gran medida de cómo preparas tus datos.

1. Estructura de Documento Clara

La construcción del grafo de conocimiento de LightRAG depende en gran medida de las señales estructurales en los documentos. Los archivos Markdown con jerarquías de encabezados claras (H1, H2, H3) tienen un rendimiento significativamente mejor que el texto plano sin estructura.

Si tu material está en PDF, considera convertirlo a Markdown antes de subirlo.

2. Un Documento, Un Tema

Meter "todo sobre Python" en un único PDF de 1,000 páginas es mucho menos efectivo que dividirlo en documentos separados: "Sintaxis Básica de Python," "Estructuras de Datos de Python," "Programación Asíncrona de Python."

Cuanto más enfocado sea el tema, menos interferencia durante la recuperación.

3. Agregar Títulos y Resúmenes Descriptivos

Agrega una breve descripción al principio de cada documento para decirle a DeepTutor qué contiene:

Estos metadatos influyen en cómo se etiquetan los nodos del grafo de conocimiento, haciendo que las consultas relevantes apunten con más precisión a este documento.

4. Mantén tu Base de Conocimientos Actualizada

Tus notas evolucionan, tu comprensión se profundiza—tu base de conocimientos también debería hacerlo.

Hábito recomendado: haz una revisión semanal de tus notas de aprendizaje y agrega contenido nuevo valioso a la base de conocimientos apropiada. No necesitas reconstruir desde cero cada vez—DeepTutor soporta subidas incrementales, y los nuevos documentos se integran automáticamente en el grafo de conocimiento existente.

5. Prueba la Calidad de Recuperación

Después de subir, intenta hacer algunas preguntas donde sabes dónde están las respuestas en tus documentos—confirma que DeepTutor puede encontrar los pasajes correctos. Si la calidad de recuperación no es satisfactoria, empieza revisando el formato del documento, luego considera dividirlo más.

Base de Conocimientos + Quiz: La Combinación Más Poderosa

Uno de los usos más poderosos de una base de conocimientos es emparejarlo con el modo Quiz para pruebas de recuerdo activo:

"(Usando base de conocimientos: Notas de Diseño de Sistemas)
Basándote en el capítulo del teorema CAP en mis notas,
dame tres preguntas basadas en escenarios—presenta un escenario de diseño de sistema
y pregunta si debería elegir un sistema CP o AP, con justificación."

DeepTutor genera preguntas basadas en tus notas reales, no en preguntas genéricas del teorema CAP de internet. Esta distinción importa—estás probando si recuerdas lo que organizaste, no si conoces la respuesta estándar del libro de texto.

Consideraciones de Privacidad

Si estás subiendo documentos sensibles (materiales internos de la empresa, datos personales), asegúrate de que estás ejecutando una instancia de DeepTutor auto-hospedada, no ningún servicio hospedado por terceros.

En la versión auto-hospedada, todos los datos de la base de conocimientos se almacenan en tu máquina local o en tu servidor. La indexación semántica de LightRAG también se procesa localmente—las llamadas API solo van a los proveedores LLM (OpenAI, Anthropic) durante la inferencia conversacional, y tus datos brutos de la base de conocimientos nunca se envían.

Si quieres evitar incluso las llamadas API, usa Ollama con un modelo local como backend para una configuración de Q&A de base de conocimientos privada completamente desconectada.
