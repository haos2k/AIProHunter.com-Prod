Instalación de CMUX y configuración del CLI: en marcha en 10 minutos

29 3月 2026·3 min read

La instalación en sí no es complicada, pero si no tienes claros algunos detalles, te quedarás atascado al usar el CLI más adelante. Este artículo recorre el proceso completo, desde la instalación hasta la verificación, y explica por qué es necesario configurar el CLI y cuándo lo necesitarás.

Dos métodos de instalación

Método 1: DMG (recomendado)

Descarga el .dmg desde la web oficial, ábrelo y arrastra CMUX a la carpeta «Aplicaciones». Eso es todo. Las actualizaciones posteriores las gestiona automáticamente Sparkle, el sistema integrado de CMUX, sin que tengas que hacerlo manualmente.

La primera vez que abras la aplicación, macOS puede mostrar una ventana de confirmación preguntando si quieres abrir «una aplicación de un desarrollador identificado». Haz clic en Abrir.

Ventaja de este método: sencillo, actualizaciones automáticas y solo necesitas descargarlo una vez.

Verificar que la instalación fue exitosa

Abre CMUX. Deberías ver:

  • Una barra lateral con pestañas verticales en el lado izquierdo (es el rasgo distintivo de CMUX, no las pestañas horizontales de tmux)
  • Un espacio de trabajo inicial ya creado
  • Un terminal listo para recibir comandos

Si ves estos tres elementos, la instalación ha sido exitosa.

Configuración del CLI: por qué es necesaria

CMUX incluye una herramienta CLI llamada cmux que te permite controlar CMUX directamente desde el terminal: listar espacios de trabajo, enviar notificaciones, ejecutar scripts de automatización, todo depende de ella.

Dentro del terminal de CMUX, el CLI está disponible automáticamente, sin configuración adicional.

Mecanismo de actualización automática

Los usuarios que instalaron con DMG no tienen que preocuparse por las actualizaciones manuales. CMUX verifica automáticamente si hay actualizaciones nuevas a través de Sparkle y, cuando las hay, verás un aviso en la barra de título. También puedes activarlo manualmente: barra de menús → cmux > Buscar actualizaciones.

Los usuarios de Homebrew actualizan con brew upgrade --cask cmux.

Requisitos del sistema (verificación rápida)

  • macOS 14.0 (Sonoma) o superior
  • Compatible con Apple Silicon e Intel Mac
