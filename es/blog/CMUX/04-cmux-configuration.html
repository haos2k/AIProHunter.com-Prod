Guía completa de configuración de CMUX: fuentes, colores, scroll y paneles divididos

29 3月 2026·4 min read

Con la configuración suele pasar que uno solo va a buscarla cuando se queda atascado. Pero como CMUX hereda la configuración de Ghostty, si no has usado Ghostty antes puede no ser obvio qué archivo hay que editar. Este artículo lo organiza todo de una vez.

Dónde está el archivo de configuración

CMUX busca en estas dos ubicaciones, en orden:

~/.config/ghostty/config
~/Library/Application Support/com.mitchellh.ghostty/config

Se recomienda usar siempre la primera ruta: es más intuitiva y más fácil de versionar con Git.

Si el archivo de configuración aún no existe, créalo:

Abre ese archivo con tu editor preferido y escribe dentro toda la configuración que sigue.

Configuración de apariencia

Fuente

font-family = JetBrains Mono
font-size = 14

Escribe en font-family el nombre de la fuente que tengas instalada en el sistema. Si no existe, CMUX usará la fuente por defecto. Para código se recomienda JetBrains Mono o Fira Code, según el gusto personal.

Colores y tema

Puedes usar un tema predefinido o especificar cada color individualmente:

# Usar un tema integrado
theme = Dracula

# O personalizar color por color
background = #1e1e2e
foreground = #cdd6f4
cursor-color = #f5e0dc
cursor-text = #1e1e2e
selection-background = #585b70
selection-foreground = #cdd6f4

Elige una de las dos opciones; no las uses simultáneamente. Si tienes preferencia por temas como Catppuccin, One Dark o Nord, escribe directamente el nombre del tema sin ajustar los colores manualmente.

Apariencia de los paneles divididos

Con varios paneles abiertos, oscurecer ligeramente los paneles que no están en foco hace que el área de trabajo principal destaque visualmente:

# Opacidad del panel sin foco (0.0 completamente transparente ~ 1.0 completamente opaco)
unfocused-split-opacity = 0.7

# Color de relleno del panel sin foco
unfocused-split-fill = #1e1e2e

# Color del divisor entre paneles
split-divider-color = #45475a

El valor unfocused-split-opacity = 0.85 es el punto de equilibrio más habitual: suficientemente oscuro para distinguirlo, pero sin que impida ver la salida de los paneles adyacentes.

Configuración de comportamiento

Líneas de historial de scroll

scrollback-limit = 10000

Los agentes de IA generan mucha salida. Si los logs son largos y quieres desplazarte hacia arriba, este valor debe ser suficientemente alto. El valor por defecto puede quedarse corto; entre 50000 y 100000 es más seguro.

Directorio de trabajo por defecto

working-directory = ~/Projects

Los nuevos espacios de trabajo o paneles comenzarán en este directorio. Es conveniente apuntarlo al directorio raíz de tus proyectos.

Configuración dentro de la aplicación

Algunas opciones se configuran dentro de la aplicación de CMUX, no en el archivo de configuración:

Barra de menús → cmux > Preferencias (⌘,):

Modo de tema: sistema (sigue a macOS), claro u oscuro.

Modo de automatización (importante): controla el nivel de acceso a la API de socket:

  • Desactivado: no expone el socket; la opción más segura, adecuada para máquinas compartidas.
  • Solo procesos de cmux: únicamente los procesos iniciados dentro del terminal de CMUX pueden conectarse —la opción más habitual.
  • allowAll: cualquier proceso local puede conectarse; adecuado para máquinas personales con automatización intensiva.

En un equipo de desarrollo personal, lo habitual es elegir «Solo procesos de cmux». Solo conviene usar allowAll en entornos de CI o en escenarios con muchos scripts.

Comportamiento de los enlaces del navegador: en «Preferencias > Navegador» puedes configurar dos listas:

  • Hosts que se abren en el navegador integrado: al hacer clic en un enlace desde la salida del terminal, qué hosts se abren en el navegador interno de CMUX.
  • Hosts que permiten HTTP: qué hosts HTTP (no HTTPS) pueden abrirse en el navegador integrado; por defecto incluye localhost y 127.0.0.1.

Ejemplo de configuración completa

Puedes copiar esta configuración directamente y ajustarla según tus necesidades:

# ~/.config/ghostty/config

# Fuente
font-family = SF Mono
font-size = 13

# Tema
theme = One Dark

# Scroll
scrollback-limit = 50000

# Paneles divididos
unfocused-split-opacity = 0.85
split-divider-color = #3e4451

# Directorio de trabajo
working-directory = ~/code

Guarda el archivo y reinicia CMUX para que los cambios surtan efecto.
