Instalación y Quick Start de Gstack: Nueve Skills en 10 Minutos

19 4月 2026·5 min read

La mayoría de las "guías de instalación" de herramientas son así: diez pasos, algo falla en el paso siete, empiezas a buscar mensajes de error en Google, dos horas después todavía no funciona.

Gstack es diferente — la instalación realmente son solo dos comandos, y Claude ejecuta todo el proceso por sí solo.

Los únicos requisitos previos: Claude Code, Git y Bun v1.0+. Si tienes los tres, sigue leyendo.

Instalación Personal (Más Común)

Abre Claude Code y pega este comando para que Claude lo ejecute:

Claude:

  • Clonará todo el repositorio en ~/.claude/skills/gstack/
  • Creará symlinks para cada skill
  • Compilará el binario de Chromium necesario para /browse (unos 58MB, compatible con macOS y Linux)
  • Instalará node_modules

Todo el proceso lleva unos 2-5 minutos, principalmente esperando que se compile el binario. Sin configuración de PATH, sin sudo requerido — todo vive dentro de .claude/.

Verificar la Instalación

Después de la instalación, prueba cualquier slash command dentro de Claude Code:

/plan-ceo-review

Si Claude empieza a hacerte preguntas como "¿Qué funcionalidad o idea quieres evaluar?" — la instalación fue exitosa.

Si no ocurre nada, comprueba si los symlinks se crearon correctamente:

Deberías ver un directorio gstack/ y symlinks para cada skill (plan-ceo-review, review, ship, etc.).

Instalación en Equipo (Opcional)

Si quieres añadir Gstack a un repositorio para que todo el equipo lo comparta:

Esto hace commit de los archivos de skill (prompts en Markdown) en tu repositorio — excluyendo el binario, que cada persona necesita compilar ejecutando setup una vez. Los compañeros de equipo ejecutan ./setup después de su primer checkout y ya están listos.

Problemas Comunes

P: ¿./setup se queda atascado a mitad de camino?
Normalmente ocurre durante la compilación del binario. Confirma que Bun es versión 1.0 o superior, y si es una versión antigua, actualiza primero: bun upgrade.

P: /browse está instalado pero Chromium falla al iniciar?
Confirma que estás en macOS o Linux (x64 / arm64). Windows actualmente no soporta las funciones del navegador en /browse y /qa, pero todos los demás skills funcionan bien.

P: ¿Cómo actualizo a la última versión?
Ejecuta /gstack-upgrade dentro de Claude Code. Detecta automáticamente tu método de instalación (global o dentro del repositorio), actualiza y te dice qué cambió.

P: El consumo de tokens es mayor de lo esperado?
Cada skill de Gstack tiene algún overhead de inicialización de contexto, y las tareas de revisión complejas pueden quemar más de 10K tokens. Úsalos selectivamente — no necesitas cada skill para cada tarea. /plan-ceo-review + /plan-eng-review para el desarrollo de nuevas funcionalidades, /review + /qa antes de ir en vivo, y eso es suficiente.

Tres Cosas a Hacer Justo Después de Instalar

1. Ejecuta un /plan-ceo-review para tener una idea

Encuentra una funcionalidad o decisión que hayas estado considerando recientemente — nada formal, simplemente di "quiero añadir un sistema de notificaciones a mi app" — luego observa cómo responde el modo CEO de Gstack.

Será notablemente diferente de tus conversaciones habituales con Claude. No saltará directamente a "bien, aquí está el diseño." Te hará algunas preguntas que probablemente no habías considerado.

2. Prueba /review en código real

Elige un trozo de código que creas que "probablemente está bien" y ejecútalo a través de /review. La mayoría de la gente se sorprende un poco la primera vez — no encuentra errores tipográficos; encuentra el tipo de problemas que "normalmente no piensas pero que se romperán bajo alto tráfico."

3. Configura /setup-browser-cookies (si planeas usar /qa)

Si tu app tiene inicio de sesión, ejecuta este comando para importar tus cookies de sesión antes de ejecutar /qa — de lo contrario la IA solo prueba páginas no autenticadas y se pierde la funcionalidad importante.

Este paso es rápido. Abre un selector interactivo donde eliges las cookies de qué dominios importar, y los valores de las cookies nunca se muestran en pantalla.
