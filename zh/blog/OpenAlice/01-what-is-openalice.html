什麼是 OpenAlice？一人 AI 交易工作室的核心概念

2026 年 4 月 15 日·9 min read

你聽過那種段子吧——某個神秘的量化基金，幾十個 quant 工程師盯著螢幕，每天用 Python 跑回測、調參數、下單；然後某個月暴虧三成，然後繼續。

普通人看著這個世界，有一種直覺：這不是我能玩的遊戲。

OpenAlice 的創作者大概也覺得這很荒謬。於是他們做了一套開源 AI 交易 Agent，目標是讓一個人可以做以前需要整個小型投資團隊才能做的事——研究市場、分析基本面、執行交易、自動監控——全部靠一個對話式 AI。

「一個人的 Wall Street」到底是什麼意思

OpenAlice 的官方定位是 your one-person Wall Street。這句話要拆開來看：

它強調的不是「讓你變得很會選股」，而是讓你有能力獨自完成整個投資流程——從發現市場機會、做研究、下決策、執行交易，到自動化監控後續。

傳統流程裡，這四件事通常分屬不同角色：分析師、策略師、交易員、風控。OpenAlice 試圖讓一套 AI 系統全部擔。

當然，它能不能真的替代這四個角色，取決於你怎麼用——但光是「你可以在一個介面裡把這四件事串起來」，就已經是過去十年不存在的東西。

核心架構：四個層次

理解 OpenAlice，最快的方式是看它把功能切成哪四塊。

1. 交易層（Trading）

OpenAlice 引入了一個叫 Unified Trading Account（UTA） 的抽象層。你可以把多個券商帳戶接進來，但 AI 永遠只跟 UTA 互動，不直接碰各個券商的 API。

這個設計不只是為了方便——它的背後邏輯是：AI 做決策的對象應該是你的整體部位，而不是某個帳戶的餘額。你在 A 券商的多頭、B 券商的對沖、C 帳戶的現金，OpenAlice 看到的是一個統一的視圖。

另一個核心設計是 Guard Pipeline：你可以設置最大部位大小、冷卻時間、交易標的白名單，甚至自訂規則。這是讓 AI 執行交易時不會「胡搞」的安全護欄——AI 再聰明，也只能在你劃定的邊界裡玩。

2. 研究分析層（Research & Analysis）

OpenAlice 內建了一個 TypeScript-native 的 OpenBB 引擎，跑在 process 裡，不需要額外設置。

覆蓋的資產類別包括：股票、加密幣、大宗商品、外匯、總體經濟指標。你可以用統一的跨資產 symbol 搜尋，也可以直接用類似 Excel 公式語法的技術指標計算器。

基本面這塊，它有公司財報、財務比率、法說會日曆、內部人交易、市場異動——目前股票最深，其他資產類別持續補充中。

新聞是背景持續收集的 RSS feed，可以用 globNews、grepNews、readNews 做封存搜尋。

3. 自動化層（Automation）

OpenAlice 的核心是一個 append-only 的 event log。所有系統活動——交易、訊息、排程觸發、心跳監控——全部以有型別的 event 流過這個 log，支援即時訂閱。

這個設計讓自動化變得很乾淨：

  • Cron 排程 — 設定時間或間隔，觸發後送 event 進 log，AI 讀到 event 就執行
  • Heartbeat — 特殊的 cron job，定期審視市場狀況，只在真的有事才主動通知你
  • Webhook — 外部系統觸發（規劃中）

也就是說：OpenAlice 可以「主動」——你不需要每次都問它，它也可以在你設定的條件下主動告訴你什麼值得注意。

4. 介面層（Interface）

OpenAlice 有三個互動入口：

  • Web UI — 主要介面，有即時串流聊天、子頻道、投資組合儀表板、equity curve 視覺化
  • Telegram — 行動端存取，有交易審核面板
  • MCP Server — 工具暴露介面，讓外部 AI Agent 可以呼叫 OpenAlice 的工具；另有 MCP Ask endpoint，讓其他 Agent 直接跟 Alice 對話

最後這個 MCP 整合有點意思——你的 OpenAlice 可以成為另一個 AI Agent 的工具呼叫對象。AI 調用 AI，這條路開始有點明確的樣子。

為什麼「對話式」是對的設計

傳統量化工具的問題不是功能不夠，而是操作門檻太高：你需要寫策略程式碼、維護回測框架、串接各種 API、搞定自動部署——光是把環境跑起來，就可以消耗一個週末。

OpenAlice 的選擇是：把所有這些藏在 AI 背後，讓你用自然語言跟它溝通。

這不是「讓功能變弱」，而是「讓入場門檻從工程師變成使用者」。你還是可以設計複雜的交易規則、設置精細的 Guard Pipeline、做多資產的相關性分析——只是你不需要寫程式才能做這些事。

當然，這也意味著你對它的理解深度，決定了你能用它做多少事。 這個系列的目的就是把這個理解深度補起來。

Brain：記憶讓 AI 真的「認識你」

最後提一個很多人可能沒注意到的功能：Brain。

OpenAlice 有一個跨對話的持久工作記憶系統，外加情緒追蹤。這意味著它不需要每次對話都從頭解釋「我的投資偏好是什麼、我在關注哪些標的、上次我們討論到哪裡」——它記得。

這看起來是小事，但如果你用過 ChatGPT 做研究，你大概體驗過那種「我已經說了第三遍一樣的背景」的挫折感。Brain 解決的就是這個。

常見問題

OpenAlice 是完全自動交易嗎？ 不完全是。它可以設置自動化排程和 Heartbeat 監控，但 Guard Pipeline 讓你對執行邊界有完整控制——它在你劃定的範圍內自動，超出範圍就停。你可以讓它越來越自動，也可以保持高度人工審核，取決於你的設置。

需要哪些 API Key 才能跑？ 預設設置用你本地的 Claude Code 登入（Pro/Max 訂閱），不需要額外 API key。如果要用 Vercel AI SDK + 自己的 OpenAI/Gemini key，Claude Code 就是 optional 的。券商 API 的串接，取決於你要連接哪些帳戶。

它支援台股嗎？ 目前文件裡提到的是 equity、crypto、commodity、currency 和 macro data，台股的支援深度取決於 OpenBB 的資料覆蓋率，這部分在實際使用時需要自行確認。

整體架構的一句話

OpenAlice 不是在告訴你怎麼選股——它是在幫你把整個投資決策流程自動化、工具化、可重複執行，然後讓 AI 作為你的執行夥伴跑在這個流程裡。

這個差別，在你開始用的第一週，大概就會體會到。
