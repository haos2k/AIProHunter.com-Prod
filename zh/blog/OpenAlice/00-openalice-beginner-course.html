OpenAlice 入門課：5 篇文章帶你打造一人 AI 交易工作室

2026 年 4 月 15 日·5 min read

多數人對「AI 交易」的印象是這樣的：一個神秘的黑盒子、一堆沒人看得懂的指標、然後某天帳號歸零——如果你不是量化工程師出身，感覺根本沒有入場資格。

OpenAlice 想打破的，就是這個入場門檻。

它是一套開源的 AI 交易 Agent，把研究、分析、下單、自動化監控全部整合進一個對話式介面。你不需要寫 Python 策略、不需要架 trading server、也不需要同時盯著十個監控視窗——你只需要跟 AI 說話，然後讓它幫你跑。

這個系列的五篇文章，就是把 OpenAlice 拆開來，一站一站帶你走過。

OpenAlice 是什麼

OpenAlice 自稱是「一個人的 Wall Street」。這句話不是行銷話術，而是對它定位的精確描述：

  • 研究 — 跨資產行情（股票、加密幣、大宗商品、外匯、總體經濟），全部透過同一個介面存取
  • 交易 — 多個券商帳戶合併成一個統一工作區（Unified Trading Account），AI 只跟 UTA 互動，不直接碰券商 API
  • 自動化 — Cron 排程、Heartbeat 市場監控、Webhook 觸發，全部跑在同一個 event log 上
  • 記憶 — Brain 系統讓 AI 在每次對話之間保有工作記憶，不需要每次從頭解釋脈絡

換句話說：以前需要一個三人分析師團隊做的事，OpenAlice 試圖讓你一個人包辦。

這個系列適合誰

  • 想玩 AI 交易但不知道從哪下手的工程師或開發者
  • 已經在用手動盯盤，想把部分流程自動化的交易者
  • 對「AI Agent + 金融市場」這個交叉點好奇、想先看懂再動手的人
  • 任何覺得「量化交易好像很難」但其實只差一個好的切入點的人

系列閱讀地圖

這五篇文章各自聚焦一個面向，可以單篇閱讀，但加起來是一套完整的 OpenAlice 工作流入門：

1. 什麼是 OpenAlice？一人 AI 交易工作室的核心概念 先把整體架構建起來——為什麼「對話式交易」是 OpenAlice 選擇的路線，以及它和傳統量化工具有什麼根本差異。

2. 安裝與快速上手：5 分鐘跑起 OpenAlice 從 clone repo 到第一次對話，帶你完成環境設置、認識 Web UI 介面、完成第一個研究查詢。

3. Trading-as-Git：像版控程式碼一樣管理你的交易 OpenAlice 最有趣的核心設計——把交易流程對應到 Git 工作流：stage 訂單、commit 帶 message、push 才執行。這篇拆解為什麼這個設計讓交易決策更清醒。

4. 研究分析模組：跨資產行情與基本面一站搞定 OpenAlice 內建 TypeScript-native OpenBB 引擎，支援股票、加密幣、總體數據。這篇帶你認識行情查詢、基本面研究、新聞監控的實際用法。

5. 自動化排程與 Heartbeat：讓 AI 在你睡覺時監控市場 Cron 排程、Heartbeat 機制、Webhook 觸發。這篇讓你的 OpenAlice 從「你問它才動」變成「它主動告訴你什麼值得注意」。

建議閱讀順序

照 1 → 2 → 3 → 4 → 5 讀：先懂為什麼設計這樣、再動手安裝、接著學交易核心流程、補完研究工具、最後讓整套系統跑自動化。
