CCManager 入門課：同時跑多個 AI Agent，終端機不用再亂成一鍋粥

2026 年 5 月 6 日·5 min read

你開了三個 AI Agent，分別在跑 code review、寫測試、還有修 bug——聽起來很美好，但現實是終端機視窗跳來跳去，根本不知道哪個在等你、哪個還在跑、哪個已經出錯在那邊等你很久了。

CCManager 就是來解這個問題的。不需要 tmux，不需要複雜設定，一個 TUI 介面管好所有 AI 工作階段。

這個系列在做什麼

這套教學拆成 10 篇，從「什麼是 CCManager」到「多專案模式跨 repo 管理」，一步一步帶你從安裝到真實工作流。

不用一次讀完——認識路之後，哪裡不懂跳哪裡。

這個系列適合誰

  • 同時跑多個 Claude Code / Gemini CLI / Cursor Agent 卻覺得愈來愈難管的開發者
  • 想搞清楚 Git Worktree 怎麼跟 AI Agent 搭配的人
  • 想讓 AI Agent 跑完自動通知、不用一直盯著終端機的人
  • 從 Claude Squad 過來、想知道 CCManager 差在哪的人

10 篇文章地圖

整條學習路線長這樣：先建立認知底盤 → 裝起來跑起來 → 搞懂 Worktree 這個核心概念 → 多 AI 助手支援 → 設定客製化 → 自動化通知 → 最後到多專案模式。

  1. 什麼是 CCManager？為什麼多 Agent 時代需要它
    建立認知底盤——CCManager 的定位、跟 Claude Squad 的差異、它在解什麼問題。讀完才知道後面每一篇在優化什麼。

  2. 安裝 CCManager：三分鐘跑起來
    npm install 或 npx，兩條路任選，驗證安裝，開始第一個工作階段。不廢話，就跟著做。

  3. CCManager 介面導覽與快捷鍵全攻略
    TUI 介面的操作邏輯、預設快捷鍵、怎麼切換工作階段。用熟這篇，速度直接翻倍。

  4. Git Worktree 是什麼？為什麼 CCManager 要用它
    搞不清楚 Worktree 的話，後面幾篇會看得霧煞煞。這篇先把概念建好，一次弄懂。

  5. 建立、切換、刪除 Worktree：CCManager 的核心操作
    從 CCManager 介面直接建 Worktree、合併回主線、複製 Claude 工作階段資料——實際操作步驟全在這裡。

  6. 不只 Claude Code：CCManager 支援哪些 AI 助手
    Gemini CLI、Codex CLI、Cursor Agent、OpenCode……各個工具怎麼設定狀態偵測。

  7. 設定檔完整指南：快捷鍵、指令預設、專案級設定
    ~/.config/ccmanager/config.json 和 .ccmanager.json 能調什麼、怎麼調，一次說清楚。

  8. Status Hooks：讓 AI Agent 跑完自動通知你
    設定 idle / busy / waiting 狀態鉤子，接 noti 推通知、打 Slack webhook、甚至更新 tmux 狀態列。

  9. 多專案模式：一個介面管所有 Repo
    --multi-project 模式怎麼用、環境變數怎麼設、跨 repo 管理工作流長什麼樣。

建議閱讀順序

照 1 → 2 → 3 → 4 → 5 打底，再視需求讀 6 → 7 → 8 → 9。

時間不多的話：先讀 1 確認你真的需要這個工具，然後 2 把它裝起來，4 搞懂 Worktree，其他按需補充。

快速上手版本

一句話：npx ccmanager 跑起來 → 建幾個 Worktree 分配給不同 Agent → 設定狀態通知，不用一直盯著終端機。

細節和時機請交給後面九篇，這篇的任務到此為止：認路、排程、出發。
