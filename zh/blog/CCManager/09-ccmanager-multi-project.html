多專案模式：一個 CCManager 介面管所有 Repo

2026 年 6 月 4 日·4 min read

你同時在開發三個不同的 repo——主產品、SDK library、還有一個 side project。每個 repo 裡都有 Agent 在跑。

正常情況下你要開三個 CCManager，或是在不同目錄裡切來切去。Multi-project 模式解決的就是這件事：一個 CCManager 介面，管所有 repo。

介面的三層結構

Multi-project 模式的介面比一般模式多一層：

專案清單（Project List）
進來第一個畫面，列出所有發現的 repo。最近用過的專案排在最上面，其他照字母排。每個條目旁邊顯示 [active/busy/waiting] 的數字，一眼看出哪個專案有 Agent 需要你。

Worktree 選單（Worktree Menu）
選一個 repo 進去，顯示這個 repo 的所有 Worktree，操作跟一般模式一樣。

工作階段（Session View）
選 Worktree 進去，就是 AI Agent 的終端機。

在 Worktree 選單按 B 返回專案清單。

搜尋功能

專案清單和 Worktree 選單都有搜尋：按 / 進入搜尋模式，打字即時過濾，Escape 取消，Enter 保留過濾狀態繼續操作。

專案一多，搜尋是救命功能。養成用 / 的習慣，比滾清單快很多。

工作階段跨專案持久

切換到另一個 repo，原本 repo 的 Agent 工作階段不會停——繼續在背景跑。你切回來，它還在，狀態還在，對話還在。

這樣你可以在多個 repo 之間自由切換，所有 Agent 同時並行，不因為你去看別的 repo 就中斷。

數字鍵快速選取

兩個清單都支援數字鍵 0-9 快速選取。不用上下鍵一個一個移動，直接按數字跳過去。清單超過 10 個項目就搭配搜尋用。

最近專案

你常用的 repo 會自動記在 ~/.config/ccmanager/recent-projects.json，每次進來排在清單最前面。這個快取是跨工作階段的，關掉 CCManager 再開，最近用的 repo 還在那裡。

找不到 repo？先檢查這幾點

  1. 目錄裡有 .git 資料夾嗎？CCManager 只認有 .git 的目錄是 repo
  2. CCMANAGER_MULTI_PROJECT_ROOT 有設對路徑嗎？echo $CCMANAGER_MULTI_PROJECT_ROOT 確認一下
  3. 試試主選單的 R 鍵重新掃描

Worktree 的目錄本身不會出現在專案清單——它屬於原本 repo 的 Worktree，在 Worktree 選單裡管理，不會被當成獨立專案。
