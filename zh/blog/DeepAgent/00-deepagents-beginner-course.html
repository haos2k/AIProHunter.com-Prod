Deep Agents SDK 入門課：10 篇文章帶你打造真正會規劃的 AI 代理人

2026 年 4 月 24 日·7 min read

你有沒有遇過這種狀況：讓 AI 做一件稍微複雜一點的任務，它前三步看起來很有條理，但走到一半就開始亂——忘記自己在幹嘛、把早就處理過的東西重做一遍、最後交出一個「努力了很久但不知道在做什麼」的結果。

這不是模型不夠聰明，是框架不夠——大多數 agent 框架只是把 tool calling 包起來，卻沒有給代理人「規劃能力、記憶能力、以及處理大量資訊的地方」。

Deep Agents SDK 就是衝著這三個缺口來的。

Deep Agents SDK 是什麼

Deep Agents 是 LangChain 的一套代理人函式庫——它的定位是「代理人底盤（agent harness）」，核心的 tool calling 迴圈跟其他框架沒什麼不同，但它內建了通常需要你自己從零搭起來的那些能力：

  • 任務規劃與分解：write_todos 工具，讓代理人把複雜任務拆成步驟、追蹤進度
  • Context 管理：內建 filesystem 工具（ls、read_file、write_file、edit_file），不讓 context window 爆炸
  • 可插拔後端：filesystem 的底層可以換——記憶體、本地磁碟、跨 thread 的持久儲存、或隔離執行的 sandbox
  • 子代理人（Subagents）：task 工具讓主代理人把複雜的子任務分包給專屬代理人，各自獨立 context
  • 長期記憶：基於 LangGraph Memory Store，讓代理人跨對話記住重要資訊

底層跑在 LangGraph runtime 上，繼承了 durable execution、streaming、human-in-the-loop 這些能力。

這個系列在解什麼問題

市場上的 Deep Agents 資源主要有兩種：官方文件（完整但密度高），和各種碎片教學（快但缺乏全貌）。

這個系列的目標是第三種：每篇聚焦一個核心能力，讀完就能動手用，又不脫離整體架構。

10 篇文章從哲學背景、快速起步、到每個進階功能，順序設計過——前三篇先讀，後面可以按需要跳著讀。

系列閱讀地圖

1. 什麼是 Deep Agents？代理人框架背後的設計邏輯

為什麼 create_agent 或 LangGraph workflow 有時候不夠用，Deep Agents SDK 解決了什麼其他框架沒解決的問題——建立世界觀，再讀後面的才不會問錯問題。

2. Quickstart：5 分鐘建立你的第一個 Deep Agent

pip install deepagents、定義一個工具、跑起來。這篇少廢話多 code，讀完你手上就有一個能動的代理人。

3. 任務規劃與 write_todos：讓代理人先想清楚再做事

write_todos 是把「一直在做事但做不完」的代理人，變成「先列計畫再執行」的代理人的那個開關。這篇說清楚它怎麼運作、什麼時候代理人會自己呼叫它。

4. Filesystem 工具：用檔案管理 Context，不讓 Token 爆炸

代理人有自己的虛擬 filesystem——read_file、write_file、edit_file。複雜任務的中間產物可以寫進去，需要的時候再讀，context window 不用一直裝著所有東西。

5. 可插拔後端：In-Memory、Disk、LangGraph Store、Sandbox 怎麼選

Filesystem 的後端是可以換的。開發階段用記憶體、需要持久化換 LangGraph Store、需要執行隔離就接 sandbox。這篇講選擇邏輯，不是所有情境都需要最重的方案。

6. Subagents：用 task 工具把複雜任務分包出去

主代理人可以用 task 工具生出子代理人，把特定的子任務交給它——子代理人有自己的 context，不會汙染主代理人的對話記錄。這是大型任務的關鍵設計。

7. 長期記憶：讓 Agent 跨對話記住重要資訊

透過 LangGraph Memory Store，代理人可以把關鍵資訊存起來，下次對話再調出來用。這篇說怎麼設定、存什麼值得存、以及代理人是怎麼判斷什麼東西要記住的。

8. Skills 系統：教你的 Agent 你的規範和偏好

Deep Agents CLI 有一套 skills 機制，讓你可以定義代理人的行為規範——開發習慣、專案慣例、偏好的工作模式。這篇講 skills 的結構和什麼時候值得投資建立。

9. Deep Agents CLI：終端機裡的 Coding 代理人

CLI 是 SDK 的一個具體實作——一個可以在終端機使用的 coding 代理人，支援 skills、記憶、可以直接在你的機器或 sandbox 裡跑程式碼。這篇是整個系列的收尾。

10. 實戰場景：三種任務類型 × Deep Agents 的真實用法

前九篇是地圖，這篇是導航。研究型任務、程式開發任務、資料處理任務——各自怎麼搭配 filesystem、subagents 和記憶，才能讓代理人發揮最大效用。

一句話精華

Deep Agents 的核心主張就一個：代理人不該只是 tool calling 的包裝——它需要計畫、需要記憶、需要處理大量資訊的地方。

如果你過去建的代理人常常走到一半就不知道自己在幹嘛，這個系列值得認真讀。
