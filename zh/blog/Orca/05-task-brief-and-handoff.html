Orca 任務怎麼交給 Agent？三張可驗收的網站修改任務卡

2026 年 11 月 24 日·9 min read

「幫咖啡店把網站修好」聽起來像一句好指令，交到 agent 手上卻可能長出一個根本不存在的週末八折。它不知道店主有沒有新活動，也不知道預約網址能不能換。寫任務卡的目的很樸素：把能做的事、不能猜的事，以及交回來要看什麼，先講清楚。

Orca 的第一次操作教學展示如何為工作區選 agent；支援 agent 文件說明可從工具選單啟動不同 CLI agent。Orca 提供執行位置和審查脈絡，需求邊界仍由你定。以下三張卡是虛構青木咖啡委託的教學範本，沒有冒充本站已跑出的 agent 回覆。

任務卡的六個必填欄位

我把任務卡寫成六格：現在壞在哪、手上有哪些材料、可改哪些地方、哪些資訊不能猜、完成時畫面應怎樣、交回哪些證據。它不是作文練習。六格填得出來，才比較不會在第三輪修改時發現雙方說的「修好」不是同一件事。

卡 A：手機導覽。 問題是 390px 寬畫面中預約按鈕被導覽遮住。允許修改導覽樣式和按鈕所在元件；不能改預約連結或桌面資訊架構。完成時，附 390px 展開／收合畫面、點擊目的地、相關測試命令與結果。若原有預約連結失效，先回報，不能自己造一個新網址。

卡 B：首頁文案。 問題是首頁仍顯示已過期活動。允許移除過期區塊或改成不含日期的常態介紹。店家沒有提供新活動、折扣與價格，所以一律標為待確認，不可自行補。完成時，列出移除的舊資訊、保留的已知事實、待店主回答的問題，並附手機與桌面畫面。

卡 C：表單回饋。 問題是使用者送出後不知道是否成功。允許修改送出狀態與提示文字；不能繞過現有驗證，也不能在請求失敗時顯示成功。完成時，分別展示成功、失敗、資料不完整三種情境，說明後端回應如何影響畫面。若示範網站沒有可用後端，應先說明無法驗證真實送達，只做前端狀態演練。

交給 Agent 前，先找出共用檔案

三張卡看似獨立，實際可能都引用同一個全站樣式檔或共用按鈕元件。先粗看 repo 結構，給每張卡註明可能的共用檔案。A 與 B 若要動同一個首頁元件，可以改成先完成 A，再讓 B 從更新後的起點工作；或者把共用調整獨立成第四張卡。並行的前提是任務真的能分開驗收，不是把同一份檔案交給三個 agent 同時搶改。

Agent 啟動後，第一輪先要求它回覆「預計改哪些檔案、會跑哪些驗證、目前缺什麼資料」。這是低成本的範圍檢查。若它打算修改付款流程、重做視覺系統或新增未授權優惠，現在就能收回，不必等一大包程式碼完成。接著讓它在自己的工作區修改，交付時回報修改範圍、實際驗證與未解問題。

常見退件怎麼寫

卡 B 若出現「週末全品項八折」，退件不要只寫「內容不準」。應寫：「來源資料沒有折扣；刪除該句，保留已知商品與營業資訊；列出需店主確認的新活動欄位。」卡 C 若成功訊息在網路失敗時仍出現，指出重現步驟與預期狀態，要求只修送出流程。卡 A 若修好手機卻弄壞桌面，附兩種寬度對照，要求保留桌面排列。明確退件既節省你重新講需求的時間，也讓 agent 的下一輪變更有可驗收的終點。

可以直接貼進任務的一段文字

如果第一次只想試 A，不必先寫複雜規格。可以把這段改成自己的 repo 路徑與測試命令後使用：「問題：390px 手機畫面中預約按鈕被導覽遮住。只修改導覽樣式與按鈕所在元件，保留預約網址及桌面版資訊架構。完成條件：導覽展開和收合時按鈕可見、可點；桌面版仍正常。請先列出預計修改的檔案與驗證方式；若需要新網址、店家文案或無法啟動專案，先回報，不要猜。交付時列出 diff、實際測試命令與結果、未驗證事項。」任務卡的作用是讓 agent 有可停下來問的地方，不是把每個未知都填成假答案。

任務開始後，先看 agent 的計畫是否仍在 A 的範圍內。如果它說要重做整個導覽選單或換 UI 套件，就問這是否為解決遮擋的必要條件；若不是，收窄。若它指出按鈕其實被固定橫幅遮住，而非導覽，應更新問題描述與證據，不能硬要求它照原假設改錯地方。好的任務卡仍允許根據實際程式調整，但每次調整都留下理由。

哪些問題必須由店主回答？

預約連結是否仍有效、活動何時開始、表單資料應由誰收件，涉及店家營運。Agent 可以找出目前程式的網址、日期或收件設定，不能由此推論店主現在仍批准它們。請把問題整理成三個能直接回答的句子，附目前網站顯示的值；若沒有回覆，交付狀態標「待確認」。這比在交付日說「AI 已經幫你更新」更可信。

這些待答問題也會影響交期。技術修正與預覽可以先交；新活動何時上架，要等店主提供內容並核准。報價與進度上把兩種狀態分開寫，店主才知道現在輪到誰回答，不會把已完成的 CSS 修正也一起卡住。

這三張卡寫好後，可以先拿來對自己提問：按鈕看得到卻點不到，會退件嗎？AI 自己補了折扣，哪一句能要求它刪掉？失敗的表單仍說成功，測試能抓到嗎？若答案清楚，再把卡片交出去。下一篇用同一組任務看誰能並行、誰要等。
