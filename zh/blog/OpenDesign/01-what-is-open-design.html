Open Design 是什麼？為什麼這個 Claude Design 開源版要存在

2026 年 5 月 25 日·6 min read

2026 年 4 月，Anthropic 端出了 Claude Design——LLM 不再只寫 prose，而是直接出設計稿，社群瘋傳了一週。但是它閉源、訂閱才能用、只能跑在 Anthropic 的雲端、只能用 Anthropic 的模型、不能 self-host、不能 Vercel deploy、不能換成你自己手上那把更便宜的 agent。Open Design 就是長在這個縫裡的東西。

一句話定義

Open Design 是 Claude Design 的本地優先、開源、BYOK 替代品：同一套 artifact-first 的心智模型，但你既有的 coding agent（Claude Code、Codex、Cursor Agent、Gemini CLI、OpenCode、Qwen、Copilot CLI）就是設計引擎，由 19 個可組合的 Skills 和 71 套品牌級 Design Systems 驅動。它不出 agent，也不綁模型——你機器上裝什麼 CLI，它就用什麼。

它跟 Claude Design 差在哪

軸線 Claude Design Open Design
授權 閉源 Apache-2.0
部署 只能用 claude.ai 本地 daemon + Vercel web
Agent 綁 Opus 4.7 你機器上的 CLI 都行
月費 Pro / Max / Team BYOK，不付月費
改 prompt 不行 全部都是檔案，可改
換 model 不行 換 CLI 即可

換句話說：Claude Design 賣的是「最頂的模型 + 最緊的 UX」，Open Design 賣的是「你已經付過錢的 CLI + 開到底的可改性」。兩條路不一樣。

那它跟 Open CoDesign 又差在哪

Open CoDesign 是另一個開源 Claude Design 替代品——做得很早、做得不錯，但走的是 Electron 桌面 app 路線，把 pi-ai 包進去當 agent runtime。Open Design 走的是另一條：Web app + 本地 daemon，daemon 偵測你 PATH 上有什麼 CLI，把那個 CLI 當引擎。它沒有自帶 agent，是因為「最強的 agent 已經在你筆電上了」。

兩個專案目標一樣，姿勢不同；UX pattern 上 Open Design 也大方承認從 Open CoDesign 借了 streaming artifact、sandboxed iframe、live agent panel 這幾個觀念。

Open Design 不是什麼

避免錯誤期待，這幾件事它不做：

  • 它不是 Figma 替代品 — 沒有 vector canvas、沒有 component library 編輯器
  • 它不出 LLM — 沒有自家 model，全靠你的 CLI
  • 它不是 prompt 模板倉庫 — Skills 不是 prompt，是包含 SKILL.md + assets + references 的目錄
  • 它不接 design tokens 的圖形編輯器 — Design Systems 是 Markdown 檔，要改用文字編輯器
  • 它沒有設計協作的多人房 — 單機跑、SQLite 存、project ZIP 可下載交給同事

如果你期待的是「圖形介面拉一拉就出網頁」，這個工具不是。如果你期待的是「我在 terminal 跟 agent 聊，但希望它輸出真的設計品」——對，就是這個。

它真正解決什麼問題

最痛的場景：你想做一張提案簡報、一頁 landing、一個 mobile prototype，丟給 AI 它確實能寫出 HTML，但是輸出長得像 AI——紫色漸層、generic emoji、左邊有彩色條的卡片、Inter 拿來當顯示字體、亂編的 metric。

Open Design 的核心命題就是把這件事治好。它的策略是：

  1. 發問先行 — 還沒寫第一個像素之前，先用一張 form 鎖死 surface、audience、tone、scale
  2. 品牌規格先行 — 你貼一張截圖或網址，agent 跑五步驟協議：找到 → 下載 → grep hex → 寫 brand-spec.md → 念回給你聽，再開始改 CSS
  3. 五維自評 — 出 artifact 之前，agent 先用哲學 / 階層 / 執行 / specificity / 克制這 5 個維度給自己打 1–5 分，不到 3 分就重做
  4. P0/P1/P2 checklist — 每個 skill 有硬閘門，沒過 P0 不准 emit
  5. Slop 黑名單 — 紫色漸層、generic emoji、Inter 當顯示字體寫進 prompt 明文禁止

這套機制不保證每次都神，但比起「丟個 prompt、看天意」穩很多。下一篇我們直接動手裝，從 clone 到看到第一張 artifact 大概五分鐘。

那我什麼時候該用它

不需要等大專案。你下次要：

  • 做一張 pitch deck 但沒空打開 Keynote
  • 做一頁 SaaS landing 給朋友看
  • 設計 mobile app onboarding 三張畫面、要可以給 PM 看
  • 出週報、PM spec、OKR 表，但不想開 Notion 模板

任一件事符合，就值得花十分鐘把 Open Design 跑起來。下一篇：安裝與快速上手——從 clone 到第一張 artifact，動手才是真的學會。
