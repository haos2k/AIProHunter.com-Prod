Paperclip 的預算上限能擋住什麼？先用一個小任務看清楚

2026 年 11 月 16 日·4 min read

把研究任務交給 agent，下一個問題常常不是它會不會寫，而是它會不會反覆查、反覆改，最後花掉比文章值錢的模型額度。

Paperclip 的核心概念把預算放在公司與個別 agent 兩個層級。成本與預算說明則是設定前應讀的文件。先說清楚：有預算欄位，不等於所有外部費用都會被它攔下。不同 adapter、工具與服務如何回報用量，要以實際配置和官方文件核對。

用一張研究工單測邊界

拿「從三頁官方文件整理產品功能」當第一個測試。工作量小，來源固定，也比較容易判斷 agent 是否為了同一問題反覆呼叫模型。

  1. 在測試公司與研究 agent 設定低額預算。記下幣別、計算週期、目前已使用量及超額時的處理方式；不要憑欄位名稱猜測它會自動停止。
  2. 建立一張只允許三頁官方文件的 issue，要求輸出三項功能、來源連結和一項限制。讓任何需要新增外部服務或擴大範圍的動作先經人工確認。
  3. 執行後比對三個地方：Paperclip 顯示的用量、模型供應商帳單、工單中的活動紀錄。三者對不上時，先查哪些成本沒有被 adapter 回報。
  4. 用同一設定做第二次小任務，觀察接近上限時的提示和中止行為。只有實際跑到邊界，才能知道這個設定對你的組合有多可靠。

這是一份測試方法，不是本文已完成的花費測量。沒有模型金鑰與帳單資料，就不該寫「設定後絕不超支」或任何節省百分比。

別把審核當成萬用停止鈕

在這個案例裡，人工審核最適合放在「任務擴大」與「對外輸出」兩處。研究 agent 若想從三頁擴到整個網站，你先決定是否值得；文章要公開前，再確認來源、授權和描述。Paperclip 的核准機制文件可用來核對目前有哪些可設定的節點。

讀完後可拿走一張簡單的檢查表：預算設定值、實際供應商帳單、任務活動、人工審核點。四者一起看，才比較有機會知道費用是在哪一步長出來的。
