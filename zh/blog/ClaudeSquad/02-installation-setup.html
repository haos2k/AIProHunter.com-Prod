常見的安裝問題

cs: command not found

Homebrew 安裝的話，確認 symlink 有沒有建好：

沒有的話把 ln -s 那行再跑一遍。

手動安裝的話，確認 ~/.local/bin 在 PATH 裡：

failed to start new session: timed out waiting for tmux session

這個錯誤通常是你用的 AI 代理人（例如 claude）版本太舊。更新一下：

或者你用的其他工具的更新指令。

gh auth 失敗

確認你的 GitHub 帳號有 2FA 設定好，然後重新跑 gh auth login，選瀏覽器驗證方式通常最穩。
