什麼是 Claude Squad？多代理人時代的終端機管理工具

2026 年 5 月 8 日·6 min read

你可能已經在用 Claude Code 或 Codex 寫程式了，感覺還不錯——但某天你突然意識到，你同時要跑三件不相干的任務。

直覺反應是開三個終端機視窗，每個跑一個代理人。這樣做，前十分鐘沒問題。

然後其中一個跑完了，你不確定是哪個。你切換視窗翻了一下，搞混了另一個任務的輸出。你的 git branch 變成一個謎，因為兩個代理人同時在改同一份程式碼——然後它們開始互相覆蓋。

這就是 Claude Squad 出現的理由。

Claude Squad 是什麼

Claude Squad 是一個開源的終端機工具（用 Go 寫的），它的核心功能只有一件事：讓你在單一介面裡同時管理多個 AI 代理人的執行環境。

支援的代理人包括：

  • Claude Code（Anthropic）
  • Codex（OpenAI）
  • Gemini CLI（Google）
  • Aider
  • 任何你能在終端機跑起來的 AI coding 工具

每個任務建立一個獨立的 session——每個 session 有自己的終端機環境，更重要的是，有自己的 git worktree。這意味著你的三個任務跑在完全隔離的工作目錄裡，沒有任何覆蓋或衝突的機會。

它和直接開 tmux 有什麼不同

這是很多人第一個問的問題——我就直接用 tmux 管多個視窗不就好了？

可以，但 Claude Squad 在 tmux 之上多做了幾件事：

git worktree 整合：每個新的 Claude Squad session 不只是一個新的 tmux pane，它同時建立一個新的 git worktree。兩個代理人改不同 branch，不可能互相干擾。

任務狀態可視化：TUI 介面讓你看到每個 session 目前是在執行中、還是在等待、還是已完成，不需要一個一個切換去確認。

Diff 預覽：每個 session 改了什麼，可以在 Claude Squad 裡直接看 diff，不需要切換去跑 git diff。

Review-then-push 流程：代理人跑完之後，你可以在 Claude Squad 裡審查、commit、推送——完整的流程不需要離開這個工具。

簡單說：tmux 是通用工具，Claude Squad 是針對 AI 代理人工作流設計的專用工具。

三個核心設計決策

理解這三個設計決策，之後用起來會清楚很多。

決策一：用 tmux 當底層執行環境

Claude Squad 沒有自己重新發明 terminal multiplexer，直接用 tmux 做 session 管理。好處是穩定、成熟、行為可預期。你不需要懂 tmux 才能用 Claude Squad，但你的機器上要裝好 tmux。

決策二：用 git worktree 隔離程式碼

每個 Claude Squad session 對應一個 git worktree，跑在獨立的 branch 上。這是讓多個代理人能並行工作的關鍵——它們改的不是同一份工作目錄的副本，而是真正獨立的 branch。

決策三：TUI 作為統一的控制介面

你不需要記住哪個 tmux session 編號是哪個任務，Claude Squad 的 TUI 列出所有任務、顯示狀態、讓你用鍵盤在任務之間切換。這件事聽起來小，但當你同時跑五個任務的時候，這個設計值錢。

誰適合用 Claude Squad

適合的使用情境：

  • 你同時在推進多個獨立的開發任務，想讓代理人並行處理
  • 你需要在多個 AI 工具之間切換（有時用 Claude Code，有時用 Codex）
  • 你想讓代理人跑在背景，自己去做別的事，等它跑完再回來審查
  • 你重視代碼審查——每次代理人改了什麼，你要能清楚看到

不適合的使用情境：

  • 你每次只有一個任務，不需要並行處理
  • 你的任務之間有強依賴——任務 B 必須等任務 A 完全結束才能開始
  • 你完全信任代理人，不需要審查（這種情況很罕見，但確實存在）

FAQ

Q：Claude Squad 要付費嗎？

不，它是完全開源的工具（AGPL-3.0 授權）。你只需要自己的 AI 代理人的 API key 或授權。

Q：Claude Squad 只能用 Claude Code 嗎？

名字叫 Claude Squad，但它支援任何可以在終端機跑起來的 AI 代理人。Codex、Gemini CLI、Aider 都可以，你甚至可以設定自訂程式。

Q：它在 Windows 上能用嗎？

tmux 是 Unix 工具，所以 Claude Squad 目前主要支援 macOS 和 Linux。Windows 用戶可以透過 WSL2 使用。
