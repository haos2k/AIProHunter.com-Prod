Claude Squad 設定檔與 Profiles：讓不同任務用不同的 AI 工具

2026 年 5 月 21 日·5 min read

Claude Squad 預設用 claude（Claude Code）跑所有 session。但你不一定每次都想用同一個工具——有的任務用 Codex 更順，有的任務你想試試 Aider，有時候你只是想切到 Gemini CLI 看看效果。

設定 profiles，讓你在新建 session 的時候直接選要用哪個工具，不需要每次去修改設定檔或記住啟動指令。

測試不同模型的效果

如果你在評估不同的 AI 工具，可以同時開多個 session，每個用不同 profile，給同樣的任務，比較輸出品質——Claude Squad 的 diff 視圖讓比較變得很方便。

修改設定後不需要重啟

設定檔的修改是即時生效的——下次你建立新 session 的時候，Claude Squad 會讀取最新的設定。不需要關掉重開。

FAQ

Q：可以在同一個 Claude Squad 程序裡，同時跑 claude 的 session 和 codex 的 session 嗎？

可以。每個 session 建立的時候你可以選不同的 profile，它們跑在各自的 worktree 裡，互不影響。

Q：profiles 裡的 program 欄位可以放什麼？

任何可以在終端機裡直接執行的指令都可以——包括帶參數的指令，例如 aider --model gpt-4o --no-auto-commits。Claude Squad 會直接在 tmux session 裡跑那個字串。
