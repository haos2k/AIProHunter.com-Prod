CMUX 설정 파일 완전 가이드: 폰트, 색상, 스크롤과 분할 패널

2026년 3월 29일·6 min read

설정은 보통 사용하다가 막혔을 때 찾아보게 됩니다. 하지만 CMUX의 설정은 Ghostty에서 상속받으므로, Ghostty를 이전에 사용하지 않았다면 어느 파일을 찾아야 할지 처음에는 알기 어렵습니다. 이 글에서 전부 정리해 한 번에 파악할 수 있도록 합니다.

설정 파일 위치

CMUX는 순서대로 두 위치를 확인합니다:

~/.config/ghostty/config
~/Library/Application Support/com.mitchellh.ghostty/config

첫 번째 경로를 통일해서 사용하는 것을 권장합니다. 더 직관적이고 버전 관리도 편리합니다.

설정 파일이 아직 없다면 먼저 만드세요:

익숙한 에디터로 이 파일을 열고, 이후 설정을 모두 여기에 작성합니다.

외관 설정

폰트

font-family = JetBrains Mono
font-size = 14

font-family에는 시스템에 설치된 폰트 이름을 입력합니다. 없으면 CMUX가 기본값으로 폴백합니다. 코드 폰트로는 JetBrains Mono나 Fira Code를 추천하지만, 개인 취향에 따라 선택하세요.

색상과 테마

기본 테마를 사용하거나, 각 색상을 직접 지정할 수 있습니다:

# 내장 테마 사용
theme = Dracula

# 또는 항목별 커스터마이징
background = #1e1e2e
foreground = #cdd6f4
cursor-color = #f5e0dc
cursor-text = #1e1e2e
selection-background = #585b70
selection-foreground = #cdd6f4

둘 중 하나를 선택하고, 동시에 설정하지 마세요. Catppuccin, One Dark, Nord 등 테마 선호도가 있다면 테마 이름을 직접 입력하면 되며, 직접 색상을 조정할 필요가 없습니다.

분할 패널 외관

다중 패널 사용 시, 포커스가 없는 패널을 약간 어둡게 해 시각적으로 주 작업 영역을 더 돋보이게 만드세요:

# 포커스 없는 패널의 불투명도 (0.0 완전 투명 ~ 1.0 완전 불투명)
unfocused-split-opacity = 0.7

# 포커스 없는 패널의 채우기 색상
unfocused-split-fill = #1e1e2e

# 패널 구분선 색상
split-divider-color = #45475a

unfocused-split-opacity = 0.85는 비교적 흔한 타협 값입니다. 충분히 어두워서 구분할 수 있지만, 옆 패널의 출력을 읽을 수 없을 정도는 아닙니다.

동작 설정

스크롤백 줄 수

scrollback-limit = 10000

AI 에이전트 출력량은 보통 많습니다. 로그가 길어서 위로 스크롤하고 싶다면 이 값을 충분히 높게 설정해야 합니다. 기본값이 부족할 수 있으므로, 50000에서 100000이 더 안전합니다.

기본 작업 디렉토리

working-directory = ~/Projects

새로 열리는 워크스페이스나 패널이 이 디렉토리에서 시작합니다. 프로젝트 루트 디렉토리로 설정하는 것이 적합합니다.

앱 내 설정

몇 가지 옵션은 설정 파일이 아닌 CMUX 앱 안에서 설정합니다:

메뉴 표시줄 → **cmux > 설정 (⌘,)**에서:

테마 모드: 시스템(macOS 따라가기), 밝게, 어둡게 중 선택.

자동화 모드 (중요): 소켓 API의 접근 수준을 제어합니다:

  • 끄기: 소켓을 열지 않음, 가장 안전하며 공유 기기에 적합
  • cmux 프로세스만: CMUX 터미널에서 시작한 프로세스만 연결 가능—가장 일반적인 선택
  • allowAll: 모든 로컬 프로세스가 연결 가능, 완전히 자동화된 개인 기기에 적합

개인 개발 기기는 보통 'cmux 프로세스만'을 선택하고, CI 환경이나 스크립트 집약적인 시나리오에서만 allowAll을 고려합니다.

브라우저 링크 동작: 설정 > 브라우저에서 두 개의 목록을 설정할 수 있습니다:

  • 내장 브라우저에서 열 호스트: 터미널 출력에서 링크를 클릭할 때 어떤 호스트를 CMUX 내장 브라우저에서 열지
  • HTTP 허용 호스트: 어떤 HTTP(비 HTTPS) 호스트를 내장 브라우저에서 열 수 있는지, 기본적으로 localhost, 127.0.0.1 포함

완전한 설정 예시

이 설정을 바로 복사해 필요에 따라 조정하세요:

# ~/.config/ghostty/config

# 폰트
font-family = SF Mono
font-size = 13

# 테마
theme = One Dark

# 스크롤
scrollback-limit = 50000

# 분할 패널
unfocused-split-opacity = 0.85
split-divider-color = #3e4451

# 작업 디렉토리
working-directory = ~/code

수정 후 저장하고 CMUX를 재시작하면 적용됩니다.

CMUX란 무엇인가? 다중 에이전트 시대에 왜 필요한가

CMUX는 Ghostty 기반의 경량 macOS 네이티브 터미널로, 여러 AI 에이전트 관리를 위해 설계되었습니다. 이 글에서는 어떤 문제를 해결하는지, tmux와 어떻게 다른지, 누구에게 적합한지 명확하게 설명합니다.
