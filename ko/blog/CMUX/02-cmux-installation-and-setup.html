설치 자체는 어렵지 않지만, 몇 가지 세부 사항을 제대로 파악하지 않으면 나중에 CLI를 사용할 때 막히게 됩니다. 이 글에서는 설치부터 검증까지의 전체 과정을 살펴보고, CLI 설정이 왜 필요한지, 언제 사용하는지도 설명합니다.

두 가지 설치 방법

방법 1: DMG (권장)

공식 사이트에서 .dmg를 다운로드한 후, 열어서 CMUX를 '응용 프로그램' 폴더로 드래그하면 됩니다. 끝입니다. 이후 업데이트는 CMUX 내장 Sparkle이 자동으로 처리하므로 수동 관리가 필요 없습니다.

처음 열 때 macOS에서 '확인된 개발자의 앱을 열겠냐'는 확인 창이 뜰 수 있습니다. 열기를 클릭하면 됩니다.

이 방법의 장점: 간단하고, 자동 업데이트가 되며, 한 번만 다운로드하면 됩니다.

설치 성공 여부 확인

CMUX를 열면 다음을 볼 수 있어야 합니다:

  • 왼쪽에 수직 탭 사이드바 (CMUX의 식별 특징으로, tmux의 수평 탭이 아닙니다)
  • 이미 열려 있는 초기 워크스페이스
  • 입력을 받을 준비가 된 터미널

이 세 가지가 보인다면 설치 성공입니다.

CLI 설정: 왜 해야 하는가

CMUX에는 cmux CLI 도구가 포함되어 있어 터미널에서 직접 CMUX를 제어할 수 있습니다. 워크스페이스 목록 확인, 알림 전송, 자동화 스크립트 실행 모두 이 도구를 사용합니다.

CMUX 터미널 안에서는 CLI가 자동으로 사용 가능하며, 별도 설정이 필요하지 않습니다.

문제는 다른 터미널(예: iTerm2, 시스템 Terminal)에서 실행할 때 cmux 명령어를 찾을 수 없다는 것입니다. 이를 해결하려면 심볼릭 링크를 하나 만들면 됩니다:

자동 업데이트 메커니즘

DMG로 설치한 사용자는 수동 업데이트에 대해 걱정할 필요가 없습니다. CMUX는 Sparkle을 통해 자동으로 업데이트를 확인하며, 새 버전이 있을 때 제목 표시줄에 업데이트 알림이 표시됩니다. 수동으로 확인하려면: 메뉴 표시줄 → cmux > 업데이트 확인.

Homebrew로 설치한 사용자는 brew upgrade --cask cmux로 업데이트하면 됩니다.

시스템 요구사항 빠른 확인

  • macOS 14.0 (Sonoma) 이상
  • Apple Silicon 및 Intel Mac 모두 지원
