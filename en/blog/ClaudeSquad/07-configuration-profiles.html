Claude Squad Configuration and Profiles: Use Different AI Tools for Different Tasks

May 21, 2026·4 min read

Claude Squad defaults to using claude (Claude Code) for all sessions. But you don't always want the same tool for every task — some tasks flow better with Codex, some you want to try with Aider, sometimes you just want to switch to Gemini CLI and see how it performs.

Configure profiles and you can choose which tool to use when creating each session, without having to edit the config file or remember startup commands every time.

Config Changes Take Effect Immediately

Modifications to the config file take effect immediately — the next time you create a new session, Claude Squad reads the latest config. No restart required.

FAQ

Q: Can I run a claude session and a codex session simultaneously within the same Claude Squad process?

Yes. You can choose a different profile for each session when creating it, and they run in their own worktrees without interfering with each other.

Q: What can go in the program field of profiles?

Any command that can be run directly in a terminal — including commands with arguments, like aider --model gpt-4o --no-auto-commits. Claude Squad runs that string directly inside the tmux session.
