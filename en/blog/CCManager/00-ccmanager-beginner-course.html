CCManager Beginner Course: Run Multiple AI Agents Without Terminal Chaos

May 6, 2026·4 min read

You've got three AI Agents running — one doing a code review, one writing tests, another fixing a bug. Sounds great in theory. In reality, you're jumping between terminal windows with no idea which one is waiting for you, which is still running, and which has been stuck with an error for the past ten minutes.

CCManager is built to solve exactly that. No tmux required, no complex setup — one TUI interface to manage all your AI sessions.

What This Series Covers

This course is split into 10 articles, taking you from "what is CCManager" all the way to "managing multiple repos in multi-project mode," step by step from installation to real-world workflows.

You don't have to read it all at once — learn the map first, then jump to whatever you need.

Who This Series Is For

  • Developers running multiple Claude Code / Gemini CLI / Cursor Agent sessions who find them increasingly hard to manage
  • People who want to understand how Git Worktrees pair with AI Agents
  • Anyone who wants AI Agents to notify them when done, without staring at the terminal all day
  • Claude Squad users who want to know what makes CCManager different

The 10-Article Map

The full learning path goes: build a mental model → get it installed → understand Worktrees (the core concept) → multi-AI support → configuration → automated notifications → multi-project mode.

  1. What Is CCManager? Why You Need It in the Multi-Agent Era
    Build the mental model — CCManager's role, how it differs from Claude Squad, and what problem it actually solves. Read this first so every other article makes sense.

  2. Installing CCManager: Up and Running in Three Minutes
    npm install or npx — pick one, verify the install, start your first session. No fluff, just follow along.

  3. CCManager Interface Guide and Keyboard Shortcuts
    The TUI's interaction logic, default shortcuts, and how to switch between sessions. Master this article and your speed doubles immediately.

  4. What Is Git Worktree? Why CCManager Uses It
    If you're fuzzy on Worktrees, the next few articles will be confusing. This one builds the concept clearly, once and for all.

  5. Create, Switch, and Delete Worktrees: CCManager's Core Operations
    Build Worktrees from the CCManager interface, merge back to main, copy Claude session data — every step of the actual workflow is here.

  6. Beyond Claude Code: Which AI Assistants Does CCManager Support?
    Gemini CLI, Codex CLI, Cursor Agent, OpenCode… how to configure status detection for each.

  7. Complete Configuration Guide: Shortcuts, Command Presets, Per-Project Settings
    Everything you can configure in ~/.config/ccmanager/config.json and .ccmanager.json, explained clearly.

  8. Status Hooks: Let AI Agents Notify You When They're Done
    Set up idle / busy / waiting hooks to push desktop notifications, fire Slack webhooks, or update your tmux status bar.

  9. Multi-Project Mode: Manage All Your Repos from One Interface
    How --multi-project mode works, how to set environment variables, and what a cross-repo management workflow looks like.

Recommended Reading Order

Work through 1 → 2 → 3 → 4 → 5 as your foundation, then read 6 → 7 → 8 → 9 based on your needs.

Short on time: read 1 to confirm this tool is right for you, then 2 to install it, 4 to understand Worktrees. Fill in the rest as needed.

The Quick-Start Version

One sentence: npx ccmanager → create a few Worktrees and assign them to different Agents → configure status notifications so you don't have to watch the terminal.

The details and timing are what the other nine articles are for. This article's job is done: you've got the map, you've got a plan — now go.
