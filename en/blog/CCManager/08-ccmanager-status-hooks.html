Status Hooks: Let AI Agents Notify You When They're Done

Jun 1, 2026·3 min read

One of the biggest time sinks when running AI Agents: waiting for them.

The Agent is running. You're sitting there watching. Nothing to do, but you're afraid to switch tasks in case it gets stuck and you miss the signal. This passive waiting kills efficiency — CCManager's Status Hooks exist to solve exactly this.

What Status Hooks Are

Simply put: when an Agent's status changes, automatically run the command you specify.

There are three states:

  • idle: Agent is free, ready for a new task
  • busy: Agent is currently processing
  • waiting (most important): Agent needs your input or confirmation — requires your attention

Each state can have a corresponding hook. When the status transitions, the hook fires automatically.

Environment Variables Available in Hooks

Every time a hook fires, CCManager passes in a set of environment variables so you can include context in your notification messages:

Variable Description
$CCMANAGER_OLD_STATE The previous state (idle / busy / waiting_input)
$CCMANAGER_NEW_STATE The new state
$CCMANAGER_WORKTREE_PATH Full path to the Worktree
$CCMANAGER_WORKTREE_DIR Worktree directory name (basename)
$CCMANAGER_WORKTREE_BRANCH Git branch name for this Worktree
$CCMANAGER_SESSION_ID Unique identifier for the session

Branch name is the most useful — when you're running three Agents simultaneously, including the branch name in the notification message tells you at a glance which one is calling for attention.

A Few Practical Tips

Just setting the waiting hook is usually enough — idle and busy notifications tend to become background noise that you quickly learn to ignore. waiting is the only state where you actually need to be woken up.

Test the command in your terminal first before pasting it into the Hook configuration. Hook failures are silent — you won't know if something went wrong.

Hooks run in the Worktree directory — if your scripts use relative paths, account for this.

With notifications configured, you can go do other work and let the Agent come to you when it needs something.
