Installing CCManager: Up and Running in Three Minutes

May 11, 2026·2 min read

The worst kind of documentation makes you understand three background concepts before you can run anything. This article isn't that — just get CCManager installed, running, and verified. Done.

Prerequisites: Node.js 18 or higher, and an AI coding CLI tool like Claude Code already in use.

Two Installation Methods — Pick One

Option 1: Global Install (Recommended)

Once installed, you can run ccmanager from anywhere without the npx prefix. If you plan to use it regularly, go with this.

Option 2: Zero-Install Run

Want to try it without installing it into your system — npx downloads and runs it directly, leaving no trace. Good for a first look before committing.

First Launch

In your project directory, run:

You'll see the CCManager TUI interface — a menu-style list. This is where you'll manage all your AI sessions going forward.

The list will be empty on first launch — that's normal. You haven't created any Worktrees yet.

Create Your First Session

Select New Worktree from the menu, enter a branch name (e.g. feature/my-first-task), and CCManager will create the Git Worktree and open the corresponding session.

The session defaults to running claude (Claude Code). If you want to switch to a different AI tool, the Complete Configuration Guide covers how to set that.

Two Shortcuts to Remember First

No need to memorize everything right away — start with these two:

  • Ctrl+E: Return to the menu from a session
  • Escape: Cancel / go back

Learn the rest after you're comfortable with the basics. The full reference is in Interface Guide and Keyboard Shortcuts.

Installed, running, first session open — this article's job is done.
