Multi-Project Mode: Manage All Your Repos from One CCManager Interface

Jun 4, 2026·3 min read

You're actively developing three different repos — the main product, an SDK library, and a side project. Each repo has Agents running in it.

Normally you'd need three separate CCManager instances, or constantly switch between directories. Multi-project mode solves this: one CCManager interface, all your repos.

The Three-Layer Interface

Multi-project mode adds one layer on top of the standard interface:

Project List
The first screen. Lists all discovered repos. Recently used projects sort to the top; others are alphabetical. Each entry shows [active/busy/waiting] counts at a glance, so you can immediately spot which project has an Agent that needs attention.

Worktree Menu
Select a repo to see all its Worktrees. Operates just like standard mode.

Session View
Select a Worktree to enter the AI Agent terminal.

Press B in the Worktree menu to return to the project list.

Search

Both the project list and the Worktree menu support search. Press / to enter search mode, type to filter in real time, Escape to cancel, and Enter to keep the filter active while continuing to navigate.

When you have many projects, search is essential. Get into the habit of using / — it's much faster than scrolling.

Sessions Persist Across Projects

Switching to a different repo doesn't stop the Agents in the previous one — they keep running in the background. When you switch back, they're still there: same state, same conversation.

This means you can move freely between multiple repos, all Agents running in parallel, without interrupting any of them just because you went to check on something else.

Number Keys for Quick Selection

Both lists support number keys 0-9 for instant selection. No need to move up and down one item at a time — just press the number to jump directly. For lists longer than 10 items, combine with search.

Recent Projects

Your frequently used repos are automatically saved to ~/.config/ccmanager/recent-projects.json and appear at the top of the list when you open CCManager. This cache persists across sessions — close CCManager and reopen it, and your recent repos are still there.

Can't Find a Repo? Check These First

  1. Does the directory have a .git folder? CCManager only recognizes directories with .git as repos.
  2. Is CCMANAGER_MULTI_PROJECT_ROOT pointing to the right path? Run echo $CCMANAGER_MULTI_PROJECT_ROOT to verify.
  3. Try pressing R in the main menu to trigger a re-scan.

Note: Worktree directories themselves won't appear in the project list — they belong to the original repo and are managed in that repo's Worktree menu, not as standalone projects.
