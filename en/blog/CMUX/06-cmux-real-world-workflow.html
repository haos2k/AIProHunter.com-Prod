Real-World Multi-Agent Workflow: CMUX Patterns for Actual Development

Mar 29, 2026·4 min read

The previous five articles covered every functional block of CMUX individually. Now it's time to connect them — a real development scenario where you're running three AI Agents simultaneously, each needing its own space, where you receive completion notifications, and occasionally need to control terminal behavior through scripts.

The Scenario: Three Agents Running at Once

Say you have three things to do today:

  1. One agent implementing a new feature (Claude Code / Cursor)
  2. One running a CI-style test loop
  3. One monitoring logs to make sure nothing's blowing up

These three are independent of each other, but all need to run — and you want to see the status of all of them at a glance.

Workspace Design

Following the "workspace = task" principle, create three workspaces:

Workspace Name Color Contents
feature-auth Blue Agent output + backup shell
test-runner Orange Test command output
monitoring Gray tail -f log monitoring

All three are fully independent — scan their status in the sidebar at any time.

Preferences > Automation Mode > cmux processes only (recommended for personal dev machines)

Working Rhythm Suggestions

Start of day: Trigger the three custom commands, all three workspaces come up together — no manual configuration required.

During work: While agents are running, you don't need to watch them constantly — wait for notifications. When one arrives, switch over to review the result.

Switching contexts: Three workspaces in the sidebar, one click to switch — no more hunting through windows with ⌘Tab.

End of day: Run cmux list-workspaces to verify all workspace statuses, making sure no agent is left mid-task.

Notes for Shared Machines

If your development machine is shared (team server, CI runner), set automation mode to "Disabled" or "cmux processes only" — never use allowAll in shared environments. The latter allows any local process to connect to your CMUX socket, which is a security risk in a shared context.
